# Hit the Mole Game  

## Overview  
The **Hit the Mole Game** is a simple interactive game built using **Java and Swing**. The player must click on the mole as it appears randomly in different holes on the game board. The objective is to score as many hits as possible before the timer runs out.  

## Features  
- Graphical User Interface (GUI) using **Java Swing**  
- Random mole movements for an engaging experience  
- Score and timer display  
- Difficulty adjustments (optional feature)  
- Sound effects (optional)  

## Technologies Used  
| Technology | Description |
|------------|------------|
| Java | Main programming language |
| Swing | GUI framework for building the game |
| Timer | Used to manage mole appearance and game duration |

## Installation  

1. **Clone the repository**  
   ```bash
   git clone https://github.com/your-username/hit-the-mole-game.git
   cd hit-the-mole-game
   ```

2. **Compile the Java files**  
   ```bash
   javac HitTheMole.java
   ```

3. **Run the game**  
   ```bash
   java HitTheMole
   ```

## Game Mechanics  
1. The game board consists of **six holes** where the mole can appear.  
2. The mole appears in a random hole for a limited time.  
3. The player must click on the mole before it disappears.  
4. Each successful hit increases the score.  
5. The game runs for a fixed time, after which the final score is displayed.
